NET NAMING RULES
----------------
- MCU peripheral nets use the peripheral name:  I2S1_*, SPI2_*, I2C1_*,
  USART1_*, USART3_*, SWD_*
- Module port nets use the port prefix:  J1_*, J3_*, M1_*
- Power nets: VBUS, +3V3, VDDSPK, GND, AGND

OTHER CONNECTORS
----------------
OLED  : 1=VCC(+3V3) 2=GND 3=SCL(I2C1_SCL) 4=SDA(I2C1_SDA)
SWD   : 1=+3V3 2=SWDIO 3=SWCLK 4=NRST 5=GND
UART  : 1=+3V3 2=TX(USART1_TX) 3=RX(USART1_RX) 4=GND
SPK   : 1=SPK+ (codec BTL+) 2=SPK- (codec BTL-)
USB-C : VBUS, GND, CC1/CC2 via 5.1k to GND, D+/D- to CH340
HP    : 3.5 mm stereo jack on codec HPOUT

AUDIO NETS (NAU88C22)
---------------------
MCLK   : MCU PB4  -> codec MCLK
BCLK   : MCU PB3  <-> codec BCLK
FS     : MCU PB0  <-> codec LRC/FS
SD     : MCU PB5  <-> codec DACIN + ADCOUT (one driver at a time)
MIC    : MICBIAS -> 2.2k -> mic +; mic - -> GND; AC-coupled to MIC1+/MIC1-
SPK    : codec LSPKOUT/RSPKOUT -> J_SPK (BTL)
HP     : codec HPOUTL/HPOUTR -> 3.5 mm jack

POWER NETS
----------
VBUS   : USB-C VBUS -> AP2112K IN, VDDSPK filter + 470uF bulk
+3V3   : AP2112K OUT -> MCU, codec AVDD/DVDD, OLED, TMP102, J1/J3/M1, WS2812B
VDDSPK : filtered VBUS -> codec speaker supply
AGND   : analog ground (codec, mic) star-connected to GND at the codec

I2C ADDRESSES
-------------
0x3C  SSD1306 OLED
0x49  TMP102
0x1A  NAU88C22 codec

EXTI LINE 2 - RESOLVED
----------------------
PA2 (BTN2) and PB2 (GDO0_2) originally both selected EXTI line 2. BTN2 is
now on PA5 (EXTI line 5) in main.h and g0_pinmap.h. Note: PA3 is line 3
(M1_IRQ / PC3) and PB11 is line 11 (GDO0_1 / PA11), so neither was a valid
alternative. Keep the CubeMX .ioc in sync once it exists.
