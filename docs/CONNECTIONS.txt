LYRION CORE G0 - MASTER NET LIST
================================
Updated : 2026-10-04
Board   : Lyrion Core G0 Rev A (planning freeze)
MCU     : STM32G071CBU6, UFQFPN-48
Sources : Core/Inc/g0_pinmap.h, docs/PINOUT.md

NET NAMING RULES
----------------
- MCU peripheral nets use the peripheral name: I2S1_*, SPI2_*, I2C1_*, I2C2_*, USART1_*, USART2_*, USART3_*, SWD_*
- Module port nets use the port prefix: LL1_*, LL2_*, LMS_*
- Power nets: VBUS, 5V_SYS, +3V3, VBAT, VDDSPK, GND, AGND

CONNECTORS & HEADERS
--------------------
LL1 (Lyrion Link 1)  : 1=+3V3 2=GND 3=SCK(PA0) 4=MISO(PB14) 5=MOSI(PB15) 6=CS1(PA8) 7=GDO0_1(PA11) 8=GDO2_1(PA12)
LL2 (Lyrion Link 2)  : 1=+3V3 2=GND 3=SCK(PA0) 4=MISO(PB14) 5=MOSI(PB15) 6=CS2(PC6) 7=GDO0_2(PB2) 8=GDO2_2(PB10)
LMS (Lyrion Smart)   : 1=5V 2=+3V3 3=GND 4=TX(PC4) 5=RX(PC5) 6=CS(PC2) 7=IRQ(PC3)
OLED (1x4)           : 1=+3V3 2=GND 3=SCL(PB6) 4=SDA(PB7)
SWD (1x5)            : 1=+3V3 2=SWDIO(PA13) 3=SWCLK(PA14) 4=NRST(PF2) 5=GND
Spare UART (1x4)     : 1=+3V3 2=TX(PA2) 3=RX(PA3) 4=GND
Spare I2C (1x4)      : 1=+3V3 2=SCL(PB13) 3=SDA(PB11) 4=GND
Spare SPI (1x6)      : 1=+3V3 2=GND 3=SCK(PA0) 4=MISO(PB14) 5=MOSI(PB15) 6=CS(PC15)
ADC / DAC (1x4)      : 1=DAC1(PA4) 2=DAC2(PA5) 3=ADC1(PA6) 4=ADC2(PA7)
SPK (JST-XH 1x2)     : 1=SPK+ (codec BTL+) 2=SPK- (codec BTL-)
J_IN (3.5 mm TRS)    : Tip=L, Ring=R via AC caps to LLIN/RLIN; Switch=PC7
J_OUT (3.5 mm TRS)   : Tip=LHP, Ring=RHP; Switch=PC13

POWER ARCHITECTURE
------------------
USB-C       : 5V input, 5.1k pulldowns on CC1/CC2
Charger     : IP2312-4V35 buck charger with solder bridges (1A/1.5A/3A) and NTC thermistor
Protection  : XB5352A monolithic 1S LiPo protection (2.8V cutoff, 4.28V overcharge, short clamp)
Boost       : MT3608 1.2 MHz boost converter (steps VBAT to 5.0V on battery mode)
Power-Path  : USB 5V turns on NPN to disable MT3608 EN pin during USB connection.
              5V_SYS net runs from USB 5V (via Schottky) when plugged in, and MT3608 when on battery.
LDO         : TLV75733PDBVR (fed by 5V_SYS, regulates rock-solid +3.3V)
Speaker Rail: VDDSPK fed by 5V_SYS (full 1W audio on battery and USB)
WS2812B     : Powered by 5V_SYS
Fuel Gauge  : 2x 100k precision divider from VBAT into PB12 (ADC1_IN16)
